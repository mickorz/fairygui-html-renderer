## 三、下一阶段：P1 转向 FairyGUI 语义层（调整后的建议）

不继续堆普通网页编辑器功能，建立语义层管线：

```
AI 生成 HTML -> FairyGUI Semantic Layer -> GrapesJS 可视化编辑
    -> 语义信息保持 -> FairyGUI Converter -> FairyGUI XML
```

AI 生成的按钮不只是普通 div，而是能被识别为 GButton，并在属性面板呈现 FairyGUI 相关属性。**这是本项目区别于普通 GrapesJS 编辑器的核心竞争力。**

执行顺序：先完成 T17，再准备真实 AI HTML 样本，然后启动 P1 语义层。
