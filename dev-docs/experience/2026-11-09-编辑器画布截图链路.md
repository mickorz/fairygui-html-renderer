# 编辑器画布截图链路（ScreenCapture 不可用/viewScale 不触发渲染/前台锁）

## 问题现象

要让 FairyGUI 编辑器截出「画布中的组件区域」（与 web 渲染截图同尺寸对比）时连环踩坑：

1. 桥的 `screenshot` 命令报 `ScreenCapture API unavailable in this editor build (sc.CaptureScreenshot is not a function)`
2. OS 级 CopyFromScreen 截图截到了前台 Chrome（编辑器没被带到前台）
3. SetForegroundWindow 五连重试全部失败（Windows 前台锁）
4. `viewScale` 属性直设 0.8：工具栏显示 80% 但画布渲染没缩（LocalToGlobal 的 rect 也不变）
5. PostMessage 合成 WM_MOUSEWHEEL（wParam 带 MK_CONTROL）：触发的是滚动不是缩放
6. PowerShell 脚本中文注释报 ParserError（UnexpectedToken）

## 排查过程（关键实验）

- 编辑器 API 文档（工程内 `官方插件支持API/TsAPI/editor.d.ts`）确认 `DocumentView` 有 `viewScale` get/set、`docContainer`、`scrollPane`
- viewScale 直设后 `canvas_rect`（自加命令，LocalToGlobal 变换链）返回 rect 稳定不变 -> 属性链与渲染链分离
- zai 看图交叉验证：viewScale=1 时画布物理 1668x937（=组件 1334x750 x1.25）；80% 时物理 1334x750（=源尺寸 1:1）且完整进客户区
- PrintWindow PW_RENDERFULLCONTENT=2 截 D3D 窗口成功（被遮挡也能截）；CopyFromScreen 需要目标区域真实可见

## 根因

1. 裁剪版 FairyGUI 编辑器（Unity 裁剪构建）删掉了 UnityEngine.ScreenCapture API
2. Windows 前台锁：非前台进程的 SetForegroundWindow 被吞（GetForegroundWindow 验证失败）
3. `viewScale` setter 只是属性赋值，不走编辑器缩放的正规内部逻辑（不触发画布重渲染）；**正规缩放通道是真键盘事件**（Ctrl+滚轮，编辑器读真实键盘状态），PostMessage 合成消息的修饰键不可靠（合成 wParam 的 MK_CONTROL 位不被当作真实 Ctrl）
4. 编辑器 UI 缩放 1.25（本机 DPI）作用于 GRoot，画布缩放 0.8 与之相乘恰好 1.0：**80% 时物理 1:1**
5. LocalToGlobal 坐标链不含画布渲染缩放（viewScale 渲染不走 GObject 变换）-> canvas_rect 的 rect 不能当物理裁剪框用
6. PowerShell 5.1 把无 BOM 的 UTF-8 脚本按 GBK 解析，中文注释/字符串变乱码引发语法错误

## 解决方案（最终链路，脚本在 .agents/skills/fgui-render-diff/scripts/）

1. `open_doc`（桥命令）打开目标组件文档
2. `zoom-input.ps1`：AttachThreadInput 附加到编辑器线程破前台锁 -> SetForegroundWindow -> SendInput 真 Ctrl+滚轮 -1 档（缩到 80%，物理=源尺寸 1:1）
3. `capture-editor.ps1`：PrintWindow PW_RENDERFULLCONTENT 截全窗口（无需前台、遮挡也能截），输出客户区偏移
4. `crop-canvas.py`（PIL）：从画布外（均匀舞台区）向内颜色突变扫描第一个画布底色像素 + 多线中位，精定位画布左上角，按理论尺寸（=组件源尺寸）裁剪；右缘校验被选中框/内容干扰时仅警告（左上+理论尺寸为准）
5. zai 看裁剪图终审（边缘干净/内容完整/底色均匀）

## 预防/注意事项

- ps1 脚本必须 UTF-8 带 BOM 保存（utf-8-sig），重写时勿丢 BOM
- 缩放档数：本机 UI 缩放 1.25，SendInput -1 档（100%->80%）即物理 1:1；换机需按 DPI 换算目标档数（80% x DPI = 1.0 -> 档数 = log(目标/当前)/log(0.8/1) 向上取整，80% 一档）
- canvas_rect 只用于粗定位参考与缩放状态读数，不作为裁剪坐标真值
- 组件内容本身可能溢出画布（编辑器显示溢出、web 渲染按组件 size 裁剪）——两图对此行为一致，不是截图/裁剪错误（差异登记见 planning 遗留特性 L8）
- submodule（fairygui-agent-bridge）的 canvas_rect 改动留在 submodule 本地工作区（plugin/main.js + mcp/server.mjs），主仓不提交 submodule 指针；工程副本 plugins/agent-bridge/main.js 需同步复制后才生效（改 thirdparties 源不生效，插件加载的是工程内副本）
