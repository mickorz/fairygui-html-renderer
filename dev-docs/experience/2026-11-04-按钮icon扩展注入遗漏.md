# 按钮/标签 icon 扩展属性注入遗漏（title 注入了 icon 漏了）

## 问题现象

- 浏览器实测 Demo_Button：按钮内 `name="icon"` 的 loader 空白，按钮没图标。
- Demo_Button.xml 里明明写着 `<Button title="点我" icon="ui://9leh0eyfrpmb6"/>`。

## 排查过程

1. grep `applyIcon/applyTitle` 调用范围：`applyIcon` 只有 list item 下发（R11）在用；扩展属性注入 `injectExtensionProps`（E3）只处理了 `title`。
2. grep 真实样本确认词表：`<Button icon="ui://..."/>` 是 FairyGUI 发布 XML 的标准形态（Demo_Button/Demo_Label/WindowA 多处），与 `<Button title>` 同机制。
3. 修复后回归验证 Demo_Label 又暴露一层：它的 icon 是 **jta 动画**（`ui://...hixt1v` -> nlge1k.jta），而 loader 的 url 解析只认 image/component 两种 kind。

## 根因

1. **实现时的对称性遗漏**：Button/Label/Title 扩展组件的属性注入是一对对称操作（title -> name="title" text；icon -> name="icon" loader），实现 E3 时只做了 title 一半，没有真实样本逐属性核对（当时样本里 icon 出现频率低，且 Button 独立分支被划掉时没有连带检查属性集）。
2. **movieclip 型 icon 覆盖不足**：R11 的 applyIcon 与主 loader url 解析都只处理 image/component，漏了 `kind "other" + type "movieclip"`（jta 资源在 package.xml 里登记为 other 类）。

## 解决方案

1. `injectExtensionProps` 补 icon 下发：复用 R11 的 `applyIcon`，Button/Label/Title 三个扩展键同源取值。
2. loader url 解析（buildScene 主分支 + applyIcon）补 movieclip 分支：`loaderRes` 类型放宽为 `ImageResource | OtherResource`；loader 渲染时遇到 movieclip 资源复用 `renderJtaFrame` 渲染首帧（该函数从 `renderJtaNode` 提取共用）。
3. fixtures：ButtonIcon.xml（name=icon loader 组件）+ P3Fix 扩 btnImgIcon/btnJtaIcon（image 型与 jta 型按钮图标）两个断言，render 套件 78 -> 80 项。

## 预防/注意事项

- 划掉某个"独立分支"需求时（如 GButton/GLabel），必须连带检查它的**属性集**是否已被既有机制覆盖——机制复用≠属性全覆盖，title/icon 是两个属性两条链路。
- 扩展组件（Button/Label/Title/ComboBox...）的注入属性应成对核对：真实样本 grep 该扩展标签的全部属性词表（title/icon/selectedIcon/...），逐项确认"已注入/不适用"。
- loader/gearIcon 的 url 目标资源有三种形态：image / component / movieclip(jta)，任何"解析 ui://"的地方都要三者齐全（本次两处解析分支都漏了第三种）。
