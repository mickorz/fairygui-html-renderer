# FairyGUI 原版 UI 类覆盖与不做边界分析

> 日期：2026-11-04
> 背景：用户对照原版 `thirdparties/OpenFairy-SDK-uGUI/Assets/FairyGUI/Scripts/UI` 全部 UI 类，质询"维持不做"的逐类理由；随后决策 N1（可滚容器）与 N5（树形静态）转为做。
> 关联：运行时能力决策文档（N 编号）、遗留特性需求文档（L 编号）。

## 二、"不做"的逐类理由（三类边界，不可混记）

### 1. 无 XML 通道（永久不做，实现即死代码）

| 类 | 理由（源码核实） |
|----|------------------|
| UIPanel | Unity Editor 嵌入用面板容器，发布组件 XML 无对应节点 |
| UIPainter | 画家对象（自定义绘制），仅代码创建 |
| GRoot | 运行时舞台根，UI 树挂载点，不在任何发布包里 |
| PopupMenu | 纯代码 API 创建（new PopupMenu()），XML 无通道 |

### 2. 事件驱动机制（静态快照无触发场景；技术部分可做，按 N 编号触发）

| 类 | 原版行为 | 静态近似可行性 | 编号 |
|----|----------|----------------|------|
| ScrollPane | 拖拽/惯性/翻页/边界事件 | **可滚容器 overflow:auto（已决策做）**；惯性/翻页不可 | N1 |
| GScrollBar | 滑块跟随 ScrollPane 联动 | N1 的从动件，单独渲染仅装饰 | N1 附带 |
| Transition | 时间轴补间（每帧推进） | 初始帧即快照；CSS animation 转译成本大 | N9 |
| Relations | 容器变尺寸联动重算（27 种词表） | 快照容器尺寸不变 -> 规则永不执行；脚本重算成本最大 | N11 |
| Window | 模态/拖动/开关动画 | XML 里是普通组件（已渲染），窗口性全为运行时行为 | - |

### 3. 依赖外部运行时 / 数据无通道

| 类 | 理由 |
|----|------|
| GLoader3D | Spine/DragonBones 骨骼，需 Web 骨骼运行时（spine-ts）+ 资源管线，超出静态渲染器边界（N13 不可行） |
| GTree（数据） | **extention="Tree" 的组件，XML 只有骨架**（UIPackage 源码：component extension 字节 -> ObjectType.Tree）；TreeNode 树数据纯运行时 API 构建（GTree.treeView），发布 XML 不含树结构 |

## 三、本批决策变更（用户确认）

- N1 可滚容器：**做**。实现：组件级 overflow=scroll -> CSS overflow:auto（滚动条外观与 FairyGUI 不一致，接受）。
- N5 树形静态：**做（形态修正）**。树数据无 XML 通道 -> 可做的部分是骨架渲染 + 语义包装（tree-node.ts，一类型一文件）+ 未支持如实上报"树数据无 XML 通道"；缩进/展开等树行为无输入来源，不做等价物。
- 其余维持：N4/N8/N13/N14 永久不做；N2/N3/N6/N7/N9/N10/N11 待触发（见决策文档总表）。
