# Text 组件三方实现对比调研

日期：2026-11-04
范围：FairyGUI 原版 C#（GTextField / GTextInput / GRichTextField / GLabel）与 OpenFairy UGUI 转换（TextField / TextInput / Label 及配套）与本项目 HTML 渲染器（text-node）
说明：参考仓库 thirdparties/OpenFairy-SDK-uGUI 无 LICENSE，本文只描述解析行为与格式知识，源码引用不超过 3 行。

## 1. 组件定位

FairyGUI 的文本体系由四个类分工：

- **GTextField**：纯文本显示基类（静态文本）。内部持有自绘 `TextField` 显示对象；默认 autoSize=Both（完全自适应、不换行）、wordWrap=false，默认格式为 UIConfig.defaultFont、字号 12、黑色、行距 3。承担 text/fontSize/color/align/vAlign/autoSize/描边/阴影/单行等全部文本外观属性，以及 UBB 开关、模板变量（templateVars/SetVar/FlushVars）。
- **GTextInput**：继承 GTextField 的输入框。显示对象换成 `InputTextField`（自带光标、选区、IME、密码、maxLength、restrict 字符过滤、prompt 提示文本），构造时把 autoSize 强制为 None；额外暴露 editable/hideInput/maxLength/restrict/displayAsPassword/keyboardType/disableIME/border/borderColor/backgroundColor 与 onChanged/onSubmit 事件。编辑器 XML 中并不是独立标签，而是 text 节点带 `input="true"` 等属性。
- **GRichTextField**：继承 GTextField 的富文本。显示对象换成 `RichTextField`（htmlText 直通 + 图文混排容器），支持 HTML 子集标签（a/img/font/b/i/u 等）、行内图片、emoji、链接点击（onClickLink）。XML 中是独立标签 `richtext`。
- **GLabel**：不是文本类，而是 GComponent 扩展组件——组合一个 name="title" 的文本子对象与 name="icon" 的图标子对象。`title`/`text` 互为别名转发到 title 对象，`titleColor`/`titleFontSize` 转发到内嵌 GTextField，`editable` 在 title 为 GTextInput 时生效。XML 实例上以 `<Label title="..." icon="..." titleColor="..." titleFontSize="..."/>` 子元素表达。

本项目渲染器侧的对应关系：text 节点（含 input="true" 的输入框）由 text-node.ts 渲染；richtext 节点目前未注册渲染器；GLabel 是 component 节点，由 scene-builder 把 `<Label title>` 注入子场景 name="title" 的 text 节点后按普通组件渲染。

## 2. FairyGUI 原版实现要点

文件：`thirdparties/OpenFairy-SDK-uGUI/Assets/FairyGUI/Scripts/UI/GTextField.cs`（及 GTextInput.cs / GRichTextField.cs / GLabel.cs）

### 2.1 属性集

- 外观：textFormat（font/size/color/lineSpacing/letterSpacing/bold/italic/underline/strikethrough/gradientColor/specialStyle 上下标/outline+outlineColor/shadowColor+shadowOffset）、color、align（left/center/right）、verticalAlign（top/middle/bottom）、singleLine。
- 尺寸：autoSize 五值（None / Both / Height / Shrink / Ellipsis）。Both=完全自适应且不换行；Height=宽度固定、高度自适应且换行；None/Shrink/Ellipsis=固定框内排版（Shrink 缩字号适配，Ellipsis 截断加省略号）。
- 描边与阴影：`stroke`（数值，0 关闭）与 `strokeColor`；描边是向外扩的轮廓；阴影 shadowOffset 的 y 向下为正。
- 文本内容管道（SetTextFieldText）：模板变量替换（有 templateVars 时）-> maxWidth 传入 -> ubb 开启时先 XML 转义再经 UBBParser 转 htmlText，否则按纯文本。GRichTextField 覆写为 htmlText 直通（UBB 解析后或原文都走 htmlText）。
- 文本更新触发 UpdateGear(6)（gearText），颜色/描边色触发 UpdateGear(4)（gearColor）。

### 2.2 二进制发布数据（Setup_BeforeAdd，segment 5）

依次读：font、size、color、align、vAlign、lineSpacing、letterSpacing、ubb、autoSize、underline、italic、bold、singleLine、可选描边（outlineColor+outline）、可选阴影（shadowColor+shadowOffset）、可选模板开关（有则建空 templateVars 字典）、版本 3 起追加 strikethrough 与 TMP 专用软边参数。text 字符串在 segment 6（Setup_AfterAdd）。

### 2.3 XML text 节点属性（真实工程样例 + OpenFairy Schema 归纳）

通用属性（id/name/xy/size/pivot/alpha/visible/grayed/tooltips/group 等）之外，text 特有：

```
fontSize color align vAlign leading letterSpacing ubb vars autoSize
underline italic bold singleLine strokeColor strokeSize shadowColor shadowOffset
input password maxLength restrict prompt font restrictSize demoText autoClearText
```

真实样例（CC-Default / UIProject）：

```xml
<text id="n1" name="title" xy="101,11" size="412,26" fontSize="22" color="#ffffff" align="center" autoSize="none" strokeColor="#000000" text="窗口标题">
<text id="n22" ... vAlign="middle" autoSize="none" singleLine="true" text="" input="true" prompt="[i][color=#999999]Your Name Here[/color][/i]"/>
```

richtext 节点同型，常带 `ubb="true"`；文本内可含 `&lt;img src='ui://...'/&gt;`、`&lt;a href='event:xx'&gt;` 等 HTML 子集标签。GLabel 实例的扩展子元素属性：title/icon/titleColor/titleFontSize，title 为输入框时再带 prompt/password/maxLength/keyboardType。

### 2.4 UBB 语法（Utils/UBBParser.cs）

支持的标签（标签名不分大小写，`\[` 转义，残缺标签按原文输出）：

| UBB | 转换目标（内部 htmlText） |
|-----|--------------------------|
| `[url=href]..[/url]` / `[url]..[/url]` | `<a href target=_blank>`，裸 url 取正文作 href |
| `[img]src[/img]` | `<img src>` |
| `[b][i][u][sup][sub][strike]` | 同名 HTML 标记 |
| `[color=c]` / `[font=f]` / `[size=n]` | `<font color/face/size>` |
| `[align=l]` | `<p align>` |

### 2.5 模板语法（GTextField.ParseTemplate）

`{name}` 用 templateVars["name"] 替换（缺失置空）；`{name=default}` 缺失时用 default；`{}` 按字面保留；`\{` 转义为字面 `{`。运行时通过 SetVar/FlushVars 动态刷新。

### 2.6 行高与排版口径

TextFormat.lineSpacing 为像素行距（默认 3）。OpenFairy 复刻注释给出的原生口径：行盒高 round(size*1.25)、基线 round(size)、四周 2px gutter、字距只加在有宽字形之间；TMP 侧注释补充：行距合计为 round(1.25*size) + leading - 1。

## 3. OpenFairy UGUI 版实现要点

OpenFairy 用 `FAIRYGUI_TMPRO` 宏分双后端：默认 **Builtin**（自绘 uGUI 网格）与可选 **TMP**（原生 TextMeshProUGUI）。

### 3.1 Builtin 后端：OpenFairy.UGUI.TextField（Runtime/TextField.cs）

- 继承 `UnityEngine.UI.Text` 但完全自绘：OnPopulateMesh 按 Run/Quad 模型复刻 FairyGUI 排版公式（行高 round(size*1.25)、基线 round(size)、2px gutter、字距只加有宽字形之间、换行仅空格后整词回退（wordLen<20）否则单字符回退）。
- UBB 与 HTML 子集解析成 Run 流：支持 b/i/u/size/color/img/url；color 支持逗号分隔 2 色（纵向渐变）/4 色（四角）顶点渐变；font/align/sup/sub/strike 被消费但不产生排版效果（避免原样显示）。裸 `[url]body[/url]` 在 Builtin 不取正文作 href（TMP 后端支持）。
- Shrink/Ellipsis：自实现。Shrink 复刻 DoShrink（多行超高按字号二分，单行超宽按宽度比例缩一次再减 1 号）；Ellipsis 定位省略号字符索引并按行/按字裁剪。overflowMode 枚举 Default/Shrink/Ellipsis 烘焙自 XML autoSize。
- 下划线取 "_" 字形中心 UV 画条；粗体四向偏移复制 quad；斜体 skew；行内图片按标签出现序号绑定 imageSprites 数组（Migrate 烘焙 Sprite 引用），排版占位宽 = 宽+2、基线 = 高*0.8，烘成子 GameObject，运行时只更新位置显隐。
- maxWidth：XML restrictSize[1] 烘入，按该宽度换行并限制自适应宽度。

### 3.2 字体三条路（BitmapFont / ExternalFont / 系统字体）

- `bitmapFont`：.fnt 标准 BMFont 或 UIBuilder 逐字图片格式，Migrate 期 ImportFont 解析成 BitmapFont ScriptableObject（glyph 表 + 图集纹理）；`canTint` 决定能否被顶点色染色（白字图集可染，逐字图片保留原色）。
- `externalFont`：ttf/otf 文件字体，ExternalFont 用 TextCore 栅格 API（FontAsset.CreateFontAsset 临时资产）把字形像素拷进共享 Alpha8 多字号图集，按 (字号,字符) 缓存，图集满则倍增扩容；比整数 CharacterInfo 近似更精确。
- 系统字体：按 fontNames 逗号列表 Font.CreateDynamicFontFromOSFont；运行时字体在 Migrate 期烘进 prefab，不依赖静态 defaultFont。

### 3.3 描边 / 阴影 / 自动尺寸（Builtin）

- 描边：TextStroke（继承 Shadow），沿四轴向各复制一份字形顶点，宽度取 effectDistance.x；零宽度不生成副本。
- 阴影：uGUI Shadow，offset 取 (x, -y)（FairyGUI y 向下）。
- 自动尺寸：ContentSizeFitter——Both=横+纵 Preferred，Height=仅纵 Preferred（ConfigureTextLayout）；同时剪掉与自动轴冲突的 relation 规则（PrepareTextRelations）。

### 3.4 TMP 后端（TmpTextMarkup / TextAutoSize / TmpTextMaterialBuilder / TmpSpriteAssetBuilder）

- TmpTextMarkup（ITextPreprocessor）：正则把 UBB 转 TMP 标签（b/i/u/s/size/color/url/img；strike->s；font 消费；裸 url 取正文）；HTML 子集 a/font/strike/color/img 也做映射；img 转 `<sprite name>`（TmpSpriteAssetBuilder 烘内联 SpriteAsset，SizedSpriteTag 按宽高与 baseline 0.8 计算 size/voffset/scale）；渐变色 `<color=a,b,c,d>` 先占位再在 OnPreRenderText 回填顶点渐变；链接默认色 #3A67CC + 下划线，点击用 FindIntersectingLink。
- TextAutoSize：Shrink 用 TMP 原生 auto sizing（fontSizeMin=1、fontSizeMax=作者字号）；Ellipsis 用 TextOverflowModes.Ellipsis；并把富文本里的绝对 `<size=px>` 归一成百分比，参与整体缩放。
- 描边/阴影：TMP SDF 材质（TmpTextMaterialBuilder 烘 per-text 材质资产，outline/underlay 参数）；阴影窄刷新走 Migrate.TextShadows.RefreshTextShadows。
- 行距换算：TMP 的 characterSpacing/lineSpacing 以 em/100 为单位，Migrate 按 em = 100/fontSize 换算像素值。

### 3.5 输入框（TextInput / InputEditing / InputSubmit / ConfigureInput）

- Builtin：原生 uGUI InputField。text 节点带 input="true" 时，Migrate 卸掉 OpenFairy.UGUI.TextField 显示面，改挂透明常驻 Image（承接射线）+ InputField + 子 "Text"（OpenFairy.UGUI.TextField，关富文本）+ placeholder（OpenFairy.UGUI.TextField，ubb=true 渲染 prompt）。password->ContentType.Password；maxLength->characterLimit；editable=false->readOnly（只读但可聚焦）；singleLine->LineType.SingleLine。InputSubmit（ISubmitHandler）实现仅回车提交（区别于失焦误提交）；InputEditing 提供撤销/重做历史与单行 Tab。已知限制：光标像素位置可能略偏（自绘布局不填 TextGenerator），文本读写/占位切换/onChanged 正常。
- TMP：TMP_InputField + Text Area(RectMask2D) + TextMeshProUGUI；prompt 同样经 TmpTextMarkup ubb 渲染。
- GTextInput 的 restrict（正则字符过滤）、keyboardType、disableIME、border/borderColor/backgroundColor 等未映射（发布范围外）。

### 3.6 GLabel（Label.cs）与模板（TextTemplate）

- Label：Component 派生，[SerializeField] internal 接线 titleText（TextComponent）/titleInput（InputComponent）/iconLoader；`title` setter 走 SetTextWithoutNotify（程序化赋值不触发 onChanged）；icon 是 Loader sprite 开关。codegen 对每个 Label 实例生成派生类。
- 模板：XML `vars="true"` 表示文本含 {name} 模板。Editor 侧 TextTemplateCompiler 把模板编译成 literals/slots/defaults 三数组（`{name=default}` 的 default 存进 defaults，`\{`/`{}` 的字面规则同原版），base 文本、gearText 页值、本地化翻译共用同一槽表；运行时 TextTemplateState.Set/Clear/Format 纯数组填槽，零字符串解析。这是"烘焙优先"思路对原版 ParseTemplate 的静态化替代。

### 3.7 相关 gear

GearFontSize（字号 gear）、GearText（文本 gear，先找 ButtonBase/Label.title 再落到 TextField）、GearColor 的页值含描边段（"color,stroke"），描边值同步到 TextStroke/TMP 材质。

### 3.8 Editor 侧解析（FairyXml.cs Schema.Display）

解析的 text 相关 XML 属性：text（经 PublishedText 处理 autoClearText）/fontSize/leading/letterSpacing/ubb/vars/input/password/maxLength/underline/prompt/bold/italic/autoSize/singleLine/font/tmpFont/strokeColor/strokeSize/shadowColor/shadowOffset/align/vAlign/restrictSize。richtext 是独立 DisplayKind（XmlEnum "richtext"）。

## 4. 当前 HTML 渲染器实现要点

文件：`src/renderer/nodes/text-node.ts`（分发 html-renderer.ts；gear 处理 gear.ts；解析 component-parser.ts）

### 4.1 已实现

- font-size [已实现]：fontSize 属性 -> CSS px，缺省 12px（与原版默认一致）。
- color [已实现]：#AARRGGBB/#RRGGBB -> rgba()，alpha 换算（utils.ts toCssColor）；gearColor 默认页 colorOverride 优先于属性色。
- 描边 [部分实现]：strokeColor/strokeSize -> `-webkit-text-stroke:Npx color`（strokeSize 缺省按 2px，OpenFairy Schema 缺省 1，口径略偏）。近似性说明：FairyGUI 描边向外扩张 N 像素，CSS text-stroke 以字形轮廓为中心向内外各 N/2，因此同数值下 HTML 描边视觉约为原版一半粗细，且大字号下主色区域被描边色内侵。
- 自动尺寸 [部分实现]：仅 autoSize="height" -> `height:auto`（配合 pre-wrap 换行）；both/shrink/ellipsis 未实现。
- 水平对齐 [已实现]：align -> text-align（left/center/right 直接同名映射）。
- 换行与空白 [已实现]：`white-space:pre-wrap`（保留 \n 与连续空格）+ `overflow:hidden`；行高固定 `line-height:1.2`（原版为 round(1.25*size)+leading-1，见差距）。
- gear 交互 [已实现]：gearDisplay 显隐、gearXY/gearSize 默认页覆盖几何、gearColor 默认页取 "color,stroke" 的 color 段（stroke 段忽略）。
- GLabel 标题 [已实现]：scene-builder E3 把 `<Label title="..."/>`（Button/Title 同理）注入子场景 name="title" 的 text 节点 text 属性。
- 安全转义 [已实现]：文本经 esc() 全量 HTML 转义，UBB/HTML 标签会以字面文本显示（不会注入标签，安全但不解读）。

### 4.2 未实现（按 text-node.ts 与解析层核实）

- valign [未实现]：仅记入 unsupported 清单上报（"text valign 未实现"），渲染始终顶对齐。
- leading/letterSpacing [未实现]：行高固定 1.2，字距无对应属性。
- singleLine [未实现]：无 white-space:nowrap 分支。
- autoSize=both/shrink/ellipsis [未实现]。
- bold/italic/underline/strikethrough [未实现]：XML 属性被解析保留在 attrs 但未生成 CSS。
- shadowColor/shadowOffset [未实现]（可用 CSS text-shadow 近似）。
- font 字体选择 [未实现]：统一页面默认字体，无位图字体概念。
- UBB [未实现]、HTML 富文本子集 [未实现]、行内图片 [未实现]、链接 [未实现]。
- 模板 {name}/{name=default} [未实现]：vars 属性被忽略，模板文本按字面渲染。
- 输入框 [未实现]：`input="true"` 不被识别（text 节点仍按静态文本渲染），prompt/password/maxLength/restrict/editable 全部忽略；空文本输入框渲染为空 div，placeholder 不显示。
- richtext 标签 [未实现]：component-parser KNOWN_TYPES 不含 "richtext"，命中"节点类型 richtext 未支持"红框占位并上报。
- gearFontSize/gearText [未实现]：GEAR_KINDS 只登记 display/xy/size/color 四种。
- GLabel 的 icon/titleColor/titleFontSize 实例属性 [未实现]（title 文字已注入）。

## 5. 三方功能对照表

| 功能点 | FairyGUI 原版 | OpenFairy UGUI | 当前 HTML 渲染器 | 差距说明 |
|--------|--------------|----------------|------------------|----------|
| text/fontSize/color | textFormat 全量，默认 12/黑/行距3 | 烘焙进 prefab（TMP 材质或顶点色） | fontSize/color/toCssColor [已实现] | 基本对齐 |
| align 水平对齐 | AlignType 三值 | TextAnchor/TextAlignmentOptions 九宫组合 | text-align [已实现] | 对齐 |
| valign 垂直对齐 | VertAlignType 三值 | 同上组合映射 [已实现] | [未实现] 仅上报 | HTML 需改 flex 容器对齐 |
| autoSize 五值 | Both/Height/Shrink/Ellipsis/None | Builtin: ContentSizeFitter+overflowMode 自绘；TMP: auto sizing/Ellipsis [已实现] | 仅 height [部分实现] | both/shrink/ellipsis 缺 |
| leading/letterSpacing | 像素值，行高 round(1.25*size)+leading-1 | Builtin 逐字排版实现；TMP em 换算 [已实现] | [未实现] 行高固定 1.2 | 多行文本行距会偏紧/偏松 |
| 描边 stroke | 向外扩轮廓，stroke=0 关闭 | Builtin TextStroke 四向复制顶点；TMP SDF outline [已实现] | -webkit-text-stroke [近似] | CSS 居中描边视觉约一半粗；strokeSize 缺省口径 2 vs Schema 1 |
| 阴影 shadowOffset | y 向下偏移顶点复制 | Builtin Shadow(x,-y)；TMP SDF underlay 材质 [已实现] | [未实现] | text-shadow 一行可补 |
| bold/italic/underline/strike | TextFormat 布尔位 | Builtin 字形偏移/skew/_字形 UV；TMP fontStyle/标签 [已实现] | [未实现] | CSS font-weight/style 等可直映射 |
| 单行 singleLine | 关闭换行 | Builtin Overflow+不换行；InputField LineType [已实现] | [未实现] | white-space:nowrap 可补 |
| UBB 富文本 | UBBParser 十种标签转 htmlText | Builtin Run 解析（部分标签只消费）；TMP 正则转 TMP 标签 [已实现] | [未实现] 字面显示 | 可映射为受限 HTML |
| HTML 子集（richtext） | RichTextField htmlText 直通 | Builtin a/font/b/i/u/img/br；TMP 同 [已实现] | [未实现] richtext 节点整体占位 | parser 未注册 richtext 渲染器 |
| 行内图片 [img] | RichTextField 图文混排 | Builtin 子 GameObject（基线0.8/占宽+2）；TMP SpriteAsset [已实现] | [未实现] | 需包资源 URL 解析配合 |
| 链接 [url]/a | onClickLink 事件 | Builtin 矩形命中；TMP FindIntersectingLink [已实现] | [未实现] | 静态渲染可降级为样式标记 |
| 模板 {name} | 运行时 ParseTemplate + SetVar/FlushVars | 编译期烘焙 literals/slots/defaults，运行时填槽 [已实现] | [未实现] 字面显示 | 静态渲染只需 default 替换 |
| 输入框 input=true | InputTextField 全套（光标/IME/密码/restrict） | 原生 InputField/TMP_InputField 烘焙 [已实现] | [未实现] 按静态文本渲染 | prompt 占位显示是主要缺口 |
| prompt 占位文本 | InputTextField.promptText | placeholder 组件 ubb 渲染 [已实现] | [未实现] | 空文本输入框页面显示为空 |
| maxLength/restrict/password | 输入过滤 | characterLimit/readOnly/ContentType [部分实现] | [未实现] | 静态渲染影响小 |
| 字体 font/位图字体 | BitmapFont/DynamicFont 双体系 | bitmapFont(.fnt/UIBuilder)/externalFont(TextCore)/系统字体 [已实现] | [未实现] 统一默认字体 | 需 Web 字体/图片字体方案 |
| gearColor | UpdateGear(4)，可 tween，含描边段 | GearColor 主色+描边烘焙 [已实现] | 默认页静态覆盖 color，描边段忽略 [部分实现] | 静态终态可接受；描边段可补 |
| gearFontSize/gearText | UpdateGear 字号/文本 | GearFontSize/GearText 烘焙 [已实现] | [未实现] | GEAR_KINDS 未登记 |
| GLabel 组合 | title/icon/titleColor/titleFontSize | Label 接线 titleText/titleInput/iconLoader [已实现] | title 注入 [已实现]；icon/titleColor/titleFontSize [未实现] | icon 需 Loader 渲染配合 |
| 点击交互/输入事件 | EventListener 体系 | uGUI 事件烘焙 [已实现] | 静态渲染无交互 | 体系差异，非缺陷 |

## 6. 结论与可补齐建议（优先级从高到低）

1. **valign [建议补齐]**：text 节点改为 flex 容器（`display:flex; flex-direction:column; justify-content:center/flex-end;` 或 `align-items`），改动集中在 text-node.ts 一个文件。demo 工程中 vAlign="middle" 大量出现在按钮标题上，补齐后按钮文本垂直居中立即受益。
2. **leading/letterSpacing [建议补齐]**：`line-height` 按 `round(fontSize*1.25)+leading-1` 像素计算（缺省 leading=3）；`letter-spacing:${letterSpacing}px`。注意 CSS letter-spacing 会在末字符后也加间距，居中文本会偏移半个字距，与原版"只在有宽字形之间加"口径略有出入，可接受或用负 text-indent 补偿。
3. **richtext 节点支持 [建议补齐]**：component-parser KNOWN_TYPES 增加 "richtext"，渲染器复用 text 渲染路径；文本内容先按受限 UBB/HTML 映射（见第 4 条），未识别标签按原版口径"按原文输出"即可安全降级。
4. **UBB -> 受限 HTML 映射 [可行路径]**：渲染前先 `esc()` 再解析 UBB 白名单标签生成 span/b/u/i/img，闭环安全。[b]->`<b>`、[i]->`<i>`、[u]->`<u>`、[strike]->`line-through`、[sup]/[sub]->`vertical-align`、[color=c]->`<span style="color:...">`、[size=n]->`<span style="font-size:...">`、[align]->`text-align` span；[img] 需要把 ui:// 包 URL 解析为资源地址（可复用 RenderContext.toAssetUrl 思路）；[url] 静态渲染降级为带下划线+主题色的 span 并携带 data-href。建议对齐 OpenFairy 的取舍：font 标签先消费不实现（HTML 侧同样难保证字体存在）。
5. **模板 default 替换 [可补]**：vars="true" 时用与 TextTemplateCompiler 相同的字面规则（`\{` 转义、`{}` 字面、`{name=default}` 取 default、`{name}` 置空）做一次静态替换即可，无需运行时变量系统。
6. **描边口径补偿 [可补]**：将 strokeSize 放大 2 倍传入 -webkit-text-stroke（近似原版向外粗细），或改用 SVG text/paint-order 精确向外描边；同时把 strokeSize 缺省值从 2 对齐到 1。
7. **输入框静态呈现 [可补]**：识别 input="true"：有 text 渲染 text，无 text 渲染 prompt（浅色/斜体近似原版 UBB 占位样式），并输出 data-fgui-input/password/maxLength 供选择器与测试用；editable=false 可标注只读。真实输入交互超出静态渲染范围。
8. **阴影/样式布尔 [可补]**：shadowColor/shadowOffset -> `text-shadow:${x}px ${y}px 0 color`（y 已是向下为正，与 CSS 同向）；bold/italic/underline -> font-weight/font-style/text-decoration。
9. **singleLine/autoSize=both [可补]**：singleLine -> `white-space:nowrap`；autoSize=both -> 绝对定位下 `width:auto;height:auto;white-space:nowrap`（原版 Both 不换行）。
10. **gearFontSize/gearText 与 gearColor 描边段 [暂缓]**：GEAR_KINDS 扩登记与 stroke 段覆盖都是小改动，等真实工程用到再补。
11. **字体体系 [暂缓]**：Web 侧无位图字体诉求前不建 BitmapFont 等价物；ttf/otf 可后续走 @font-face，字体名映射需在包解析层收集 font 资源。
