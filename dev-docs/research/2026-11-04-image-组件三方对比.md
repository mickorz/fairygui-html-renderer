# Image 组件三方实现对比调研

日期：2026-11-04
范围：FairyGUI 原版 C#（GImage）与 OpenFairy UGUI 转换（Image）与本项目 HTML 渲染器（image-node）
说明：参考仓库 thirdparties/OpenFairy-SDK-uGUI 无 LICENSE，本文只描述解析行为与格式知识，不复制其源码。

## 1. 组件定位

GImage 是 FairyGUI 中最基础的静态图像组件：显示包内一张图片资源，无文本内容、默认不参与触摸命中（原生显示对象为 TouchDisabled，装饰外框不会挡住后方按钮）。典型用途：按钮背景、图标、九宫格边框底图、装饰线等一切静态位图。它继承 GObject（拥有 xy/size/pivot/scale/rotation/alpha/visible/grayed/tooltips 等通用属性），并实现 IColorGear 接口（支持 gearColor 染色联动控制器）。

在 FairyGUI 编辑器发布的组件 XML 中，image 是 displayList 的常见子节点，实例属性形如：

```xml
<image id="n9" name="n9" src="thi7g" xy="61,418" size="511,2"/>
<image id="n1" name="n1" src="thi7d" xy="2,0" aspect="true">
```

资源本身在 package.xml 中声明：

```xml
<image id="dwwc2" name="5.png" path="/images/" scale="9grid" scale9grid="88,78,441,243" width="615" height="387"/>
```

## 2. FairyGUI 原版实现要点（GImage.cs）

文件：`thirdparties/OpenFairy-SDK-uGUI/Assets/FairyGUI/Scripts/UI/GImage.cs`

- 内部持有 DisplayObject 侧的 `Image`（FairyGUI 自绘网格图形类，非 uGUI Image），全部视觉能力（九宫格、平铺、翻转、填充）都在该图形类中通过网格/UV 生成实现。
- 属性集：
  - `color`：乘法染色，setter 触发 `UpdateGear(4)`（gear 序号 4 即 GearColor），实现 IColorGear。
  - `flip`：FlipType（None / Horizontal / Vertical / Both），在图形层翻转绘制；翻转时九宫格网格同步翻转（左右或上下边框厚度互换）。
  - `fillMethod`：None / Horizontal / Vertical / Radial90 / Radial180 / Radial360（进度/冷却填充），配套 `fillOrigin`、`fillClockwise`、`fillAmount`（0~1）。
  - `texture` / `material` / `shader`：运行时直接换纹理或换材质（属于运行时 API，编辑器数据不含）。
- 构造（ConstructFromResource）：从 packageItem 取分支/高分辨率资源项，加载后设置 `scale9Grid`、`scaleByTile`、`tileGridIndice`、`texture`、`textureScale`，初始尺寸 = 资源原始尺寸（`SetSize(sourceWidth, sourceHeight)`）。即九宫格/平铺是资源级属性，实例级只有 size 覆盖。
- 二进制发布数据（Setup_BeforeAdd，segment 5）依次读取：color（可选，bool 前缀）、flip（byte）、fillMethod（byte）；fillMethod 非 None 时再读 fillOrigin（byte）、fillClockwise（bool）、fillAmount（float）。
- XML 编辑器格式中 image 实例可见属性（由真实工程样例与 OpenFairy 的 Schema 归纳）：通用属性 id/name/src/pkg/xy/size/pivot/scale/skew/rotation/alpha/visible/touchable/tooltips/grayed/blend/filter/filterData/group，image 特有 color/fillMethod/fillOrigin/fillClockwise/fillAmount/flip/aspect，以及 gearXxx 子元素。
- grayed 定义在 GObject 层（`public bool grayed`），同步到 DisplayObject 做灰化；按钮场景下另有 disabled 页语义（属 GButton，不属于 GImage）。

## 3. OpenFairy UGUI 转换实现要点

### 3.1 运行时（Runtime/Image.cs）

- `OpenFairy.UGUI.Image` 继承 `UnityEngine.UI.Image`（同短名，命名空间内裸 Image 指本类），额外增加 `flipX` / `flipY` 两个布尔字段。
- 覆写 `OnPopulateMesh` 处理三种情形：
  - Tiled 平铺：自绘单 quad，UV 按 wrapMode=Repeat 从原点铺出 N 格，flip 并入 UV；纵向把顶边对齐到整格边界，让残缺格落在底边，复刻 FairyGUI「从左上起铺、残缺格落在右下」的相位（Unity Y 轴向上，原生 Tiled 缺这步会纵向差半格）。
  - Sliced 九宫格 + 翻转：uGUI 基类只镜像 UV、保留未翻转的边条厚度，非对称边框会错位；此处自绘 4x4 网格，翻转轴上两条边框的屏幕厚度互换 + UV 预翻转，对应 FairyGUI 同时翻转 grid rect 与喂入预翻转 uvRect 的行为。
  - 其余（Simple/Filled）：走 uGUI 基类，再绕 sprite 自身 UV 区间镜像每个顶点实现翻转。
- 染色直接用 uGUI `Image.color` 顶点色（乘法语义与 FairyGUI 一致）。
- 灰化：grayed 烘焙期挂 `Grayed` 组件（引用 disabled 的 `ColorAdjust`，IMaterialModifier + UIColorMatrix shader 灰度矩阵）；按钮有 disabled 页时优先换页、有 grayed 控制器时切其页 1，都没有才套灰度滤镜（复刻 GButton/GComponent.HandleGrayedChanged 的判定顺序）。

### 3.2 资源导入（Editor/Migrate.cs ImportImage）

- 图片 bytes 直接写成 Unity Sprite 资产。
- 仅当 `scale="9grid"` 且有 `scale9grid` 时才设置 spriteBorder（grid "x,y,w,h" 换算为 Unity border 顺序 left/bottom/right/top，bottom/right 由宽高反算）；`scale9grid` 是编辑器保留数据，未启用 9grid 时忽略保留网格（包括负宽高缓存），不钳制后启用切片。
- `scale="tile"` 时先 TrimTransparent 去透明边，对齐图集裁剪语义，再导入为 Tiled 使用的 Sprite。

### 3.3 实例配置（Editor/Migrate.cs ConfigureImage）

- type 判定：scale=Tile 用 Tiled；sprite.border 为零用 Simple；否则 Sliced。
- color：`element.Color ?? "#ffffffff"` 填 uGUI 顶点色。
- fillMethod 非 None 时 type 改为 Filled，hz/vt/radial90/radial180/radial360 逐一映射 uGUI FillMethod；fillOrigin 按 FairyGUI 与 uGUI 枚举顺序差异逐语义映射（Vertical 的 Top/Bottom、Radial90/180/360 各自的角/边顺序）；fillClockwise 直接传；fillAmount = XML 值 / 100。
- flip 非 None 时设 flipX/flipY（hz/vt/both 组合）。
- XML Schema（Editor/FairyXml.cs 的 Display 类）解析的 image 相关属性：src/pkg/xy/size/color/fillMethod/fillOrigin/fillClockwise/fillAmount/flip/grayed/rotation/alpha/blend/filter/filterData 等；**未解析 aspect（保持纵横比），该属性被丢弃**。
- gearColor 烘焙为 GearColor<T>：values/defaultValue 主色（可 tween）+ strokeValues 描边色（离散态），Apply 时直接设 `Graphic.color`。

### 3.4 被丢弃/不做项

- aspect（纵横比约束）未解析。
- tileGridIndice（平铺网格索引）未实现，平铺只有基础 Tiled。
- 运行时 texture/material/shader 动态换图不做（烘焙优先，动态换图由 Loader 承担）。

## 4. 当前 HTML 渲染器实现要点

文件：`src/renderer/nodes/image-node.ts`、`src/renderer/utils.ts`、`src/renderer/types.ts`、`src/renderer/gear.ts`、`src/renderer/html-renderer.ts`、`src/scene/scene-builder.ts`

- 资源解析：`ctx.pkg.byId(node.src)` 取 package.xml 的 ImageResource（id/name/path/scale/scale9grid/width/height）；找不到或 kind 非 image 时上报 unsupported 并画红虚线占位框。
- 普通图 [已实现]：`<img src=...>`，节点无显式 size 时用资源原始 width/height 兜底。
- 九宫格 [已实现]：`nineSliceStyle` 生成 div + CSS border-image（source/slice/width/repeat），slice 四边按 scale9grid "x,y,w,h" 换算为 上右下左，right/bottom 反算并 clamp 到 0（容忍 9grid 区域略超小图边界）；`scale="tile"` 时 border-image-repeat 用 repeat，否则 stretch。
  - 注意判定条件：只检查 `res.scale9grid` 是否存在，不检查 `res.scale === "9grid"`。OpenFairy 的语义是「仅 9grid 时启用网格、其余忽略保留网格」，此处更宽松。
- 染色 [已实现]：`tintStyle` -> `filter:url(#tint-RRGGBB)`，页面末尾统一生成 SVG feColorMatrix 对角矩阵（RGB 通道乘法染色，alpha 恒为 1）；颜色收集进 tints 集合去重。
  - 8 位 `#AARRGGBB` 颜色取后 6 位，**alpha 分量被丢弃**（染色无法表达半透明染色）。
- gearColor [已实现]：`resolveGear` 中 kind=color 的 gear 按控制器选中页取值（值格式 "color,stroke"，取 color 段），作为 colorOverride 覆盖节点 color 属性；优先级为 gearColor 默认页覆盖 > 节点 color 属性。静态取值，无 tween。
- 灰化 [已实现]：`grayed="true"` -> `filter: grayscale(1)`，与染色 filter 拼接；按钮 disabled 页 / grayed 控制器切换语义未实现（属按钮范畴）。
- flip [已实现]：`baseStyle` 通用处理（所有节点共用），hz/vt/both -> transform scaleX/scaleY/scale。CSS 整体镜像在九宫格下等效于 FairyGUI 的「翻转网格」语义（边框厚度视觉互换）。
- rotation [已实现]：transform rotate；transform-origin 未按 pivot 处理（默认元素中心），pivot/scale/skew 均未处理（通用几何限制，非 image 专属）。
- 未实现项（以代码为准）：
  - fillMethod/fillOrigin/fillClockwise/fillAmount [未实现]：src 下无任何 fillMethod 引用，进度填充类图像会渲染为完整原图。
  - aspect [未实现]：size 与原图比例不一致时直接拉伸（img 无 aspect-ratio 约束）。
  - tileGridIndice [未实现]。
  - blendMode/filter(亮度对比度饱和度色相)/material/shader [未实现]。

## 5. 三方功能对照表

| 功能点 | FairyGUI 原版 | OpenFairy UGUI | 当前 HTML 渲染器 | 差距说明 |
|---|---|---|---|---|
| 基本显示 | 自绘网格图形，NTexture | uGUI Image + Migrate 烘焙 Sprite 直接引用 | img 标签直接引用原 PNG | 三方一致可达 |
| 资源定位 | packageItem -> 资源项 | package.xml Schema 解析 | package.xml 解析（byId） | 一致 |
| size 覆盖 | SetSize | RectTransform 尺寸 | CSS width/height | 一致 |
| 九宫格 | NGraphics 网格绘制 | 仅 9grid 时设 spriteBorder + Sliced；保留网格未启用则忽略 | scale9grid 存在即启用 border-image | HTML 侧未检查 scale=9grid 前提，边界更宽 |
| 平铺 tile | scaleByTile + tileGridIndice | Tiled 单 quad UV repeat，残缺格落底边 | border-image-repeat: repeat | tileGridIndice 双方后端均未实现 |
| 染色 color | 顶点色乘法，支持 8 位含 alpha | uGUI Image.color（ParseColor 含 alpha） | SVG feColorMatrix，alpha 恒 1 | 8 位色的 A 分量在 HTML 侧被丢弃 |
| grayed | GObject.grayed -> 显示对象灰化 | 烘焙 Grayed + ColorAdjust 材质；按钮 disabled 页优先 | filter: grayscale(1) | HTML 侧无按钮 disabled 页/grayed 控制器分支 |
| flip | FlipType 四值，网格翻转 | flipX/flipY 自绘网格或 UV 镜像 | transform scaleX/scaleY/scale | 视觉等效（九宫格边框互换语义也一致） |
| fillMethod 填充 | 5 种 + origin/clockwise/amount | uGUI Filled 原生支持，origin 逐一映射 | 未实现 | 主要缺口，进度条/冷却图标场景不可渲染 |
| aspect 纵横比 | XML 编辑器属性 | 未解析（丢弃） | 未处理 | 双方后端都缺，原版为编辑器元数据 |
| gearColor | IColorGear，UpdateGear(4)，可 tween | GearColor<T> 烘焙，主色可 tween | 默认页静态覆盖 colorOverride | HTML 为静态终态，无动画（静态渲染可接受） |
| blendMode/滤镜 | 支持（shader 级） | BlendModeEffect / ColorAdjust 烘焙 | 未实现 | 低频，暂缓合理 |
| 运行时换图 texture | 支持 | 不做（Loader 承担） | 静态渲染不适用 | 体系差异，非缺陷 |
| 触摸/raycast | 显示对象 TouchDisabled | raycastTarget=false 烘焙 | 无交互渲染 | 体系差异，非缺陷 |

## 6. 结论与可补齐建议（优先级从高到低）

1. fillMethod 填充 [建议补齐]：进度条、技能冷却、环形进度是 UI 高频元素。可用 CSS `clip-path`（hz/vt）与 SVG 约合 `conic-gradient` mask（radial 系列）近似实现，radial 的 origin/clockwise 需按 uGUI 的枚举映射表照抄语义。
2. 染色 alpha [建议补齐]：8 位色时把 A 换算为附加 opacity（需注意与节点自身 alpha 的复合关系），改动小。
3. 九宫格启用条件 [建议对齐]：nineSliceStyle 增加 `res.scale === "9grid"` 判定，未启用 9grid 的保留网格按整图渲染，与 OpenFairy 语义对齐。
4. aspect 纵横比 [可补]：img/div 加 `aspect-ratio: w / h` 或按比例约束一维，改动小、收益低频。
5. pivot/scale 旋转基点 [通用项]：baseStyle 增加 transform-origin（按 pivot 换算），属于全部节点共享的几何精度问题，非 image 专属。
6. grayed 的按钮 disabled 页/grayed 控制器语义 [暂缓]：属按钮交互态，静态渲染影响有限。
7. tileGridIndice、blendMode、滤镜四参数 [暂缓]：低频高级特性，等真实工程用到再补。
