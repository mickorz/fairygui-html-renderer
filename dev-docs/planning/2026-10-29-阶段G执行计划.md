## 技术决策

- **无人值守提取（browser-extractor）**：不引入 Playwright——提取脚本注入样本 HTML（`</body>` 前插入，把 JSON 写入隐藏 `<pre id="__extract__">`），Chrome headless `--dump-dom` 输出执行后 DOM，Node 端解析脚本结果。零新依赖、可脚本化重复执行
- **提取发生在浏览器渲染后**：getBoundingClientRect 天然覆盖 Flex/Grid（导出计算后最终位置，v3 要求自动满足）；React 构建产物即 HTML，天然覆盖
- **递归映射（style-mapper）**：容器 div → 子组件（递归成组件文件）；纯色背景容器 → 先输出 graph 背景节点再挂子节点；img → image；带文字元素 → text；透明度 → alpha、rotate → rotation；无法表达的特性进报告 skipped
- **确定性 id（fairy-writer）**：djb2 内容哈希 → base36 取 5 位，同内容同 id，重复导出资源不冲突
- **validator**：转换后回读断言（节点数、逐节点坐标 ±1px 对照提取 JSON）+ 转换报告（总数/原生/跳过及原因）
- 明确不做：渐变/阴影/SVG 烘焙（报告 skipped，后续按需）；React 状态与事件

## 模块结构（src/convert/ 重构扩展）

| 模块 | 职责 |
|---|---|
| extractor.ts | 注入提取脚本 + CLI（样本.html → 提取 JSON） |
| style-mapper.ts | 提取 JSON → FGNode 树（容器递归成组件、graph/opacity/rotation 映射、报告） |
| fairy-writer.ts | FGNode 树 → package.xml/组件 XML/图片（确定性 id、隔离写入） |
| validator.ts | 回读对照报告 |
| transform.ts | 流水线编排 CLI：extract → map → write → validate（保留 F 的 transform 入口兼容） |
