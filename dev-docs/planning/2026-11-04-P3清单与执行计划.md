## 二、本批（阶段 K）执行范围（已完成，见阶段K-执行报告）

1. **movieclip 首帧渲染**：package.xml movieclip 资源解析帧图引用，组件 movieclip 节点静态渲染首帧（frame 属性指定帧优先，缺省第 0 帧）。
2. **gear 系列登记与默认页求值**（gear.ts + parser GEAR_KINDS 扩展）：
   - gearLook：touchable/grayed 按页取值（静态渲染消费 grayed）
   - gearText：文本内容按页替换
   - gearFontSize：字号按页覆盖
   - gearIcon：loader url 按页覆盖（复用 icon 解析通路）
   - gearAni：动画帧按页取值（静态渲染取帧）
   - gearDisplay2：condition 条件显示（静态取默认可见性，条件不满足场景如实降级）
3. 验收：fixtures + 断言扩展，四套件回归全绿，浏览器实测真实样本。

## 三、明确不做（维持既有边界）

运行时交互（滚动/选中/虚拟列表/换页）、动画播放、Relations 同步、外部资源加载、GLoader3D、polygon SVG、字体体系、clipSoftness、tileGridIndice/blendMode/滤镜、radial90/180/270、loader fill 对组件内容。
