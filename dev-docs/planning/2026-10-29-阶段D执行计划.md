## 技术决策

- **MCP stdio server，零新依赖**：手写 JSON-RPC 2.0（换行分隔）实现 initialize / tools/list / tools/call，约百行；pi 经 `.pi/mcp.json` 接入（`mcp__fairygui__*` 前缀）
- **截图用系统 Chrome headless CLI**（`--headless=new --screenshot --virtual-time-budget`），不引入 Playwright/puppeteer——等待 focus 高亮 JS 执行后截图；Chrome 路径按 `CHROME_PATH` 环境变量 → 常见安装位置探测
- **产物走 file:// URL**：render_component 写 HTML 到系统临时目录，资源用 file:/// 绝对 URL（避免跨盘相对路径问题）；不占用 HTTP 服务端口，MCP 进程自包含
- **分工边界**：本项目 MCP 提供 list/locate/render/screenshot 四个确定性工具；浏览器交互（打开页面、人工/视觉核验）由 pi-browser-use 等既有浏览器工具承担
- 坐标约定：工具返回 FairyGUI 设计坐标（xy/size）；浏览器实际坐标由 DOM 测量，不混用

## 工具定义

| 工具 | 输入 | 输出 |
|---|---|---|
| list_components | `{ package? }` | 包列表或包内组件清单（id/name/exported/相对路径） |
| locate_component | `{ query }` | 匹配节点列表（component/name/id/path/key/unsupported，复用实时搜索） |
| render_component | `{ key }` | 写出 HTML（file:// URL）+ 节点信息（path/key/xy/size 设计坐标/sourceFile） |
| screenshot_component | `{ key, width?, height? }` | render + Chrome headless 截图 → PNG 绝对路径 |
