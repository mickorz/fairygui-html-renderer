## 技术决策

- Node 原生 `http` 模块，**零新依赖**；测试用 Node 原生 fetch，无测试框架
- 工程根：环境变量 `FGUI_PROJECT_ROOT`，默认 `./CC-Default`
- 服务模式解析策略：每请求重解析（`getComponent(file, { fresh: true })`，衔接 A4），不做常驻缓存
- 前端为服务端内嵌的零构建 vanilla 页面（包列表 → 组件列表 → iframe 渲染画布），无框架

## 接口设计

| 路由 | 输入 | 输出 |
|---|---|---|
| `GET /api/project` | - | 工程信息 + 包列表（id/name） |
| `GET /api/packages/:pkg/components` | 包名 | 组件清单（id/name/exported/相对路径） |
| `GET /api/scene?component=Bag/BagWin.xml` | 包内相对路径 | Scene Tree JSON（核心数据模型，path+key 双标识） |
| `GET /api/assets/<包内路径>` | - | 资源文件（图片等，带 Content-Type） |
| `GET /view?component=...` | 包内相对路径 | 渲染后的完整 HTML（iframe 消费，选择器可用） |
| `GET /` | - | 工作区前端页面 |

安全：所有路径参数 decodeURIComponent 后经统一守卫 `safeResolve`（resolve 后必须仍在工程根内），拒绝绝对路径注入与目录穿越。

## 结构性重构（B1）
