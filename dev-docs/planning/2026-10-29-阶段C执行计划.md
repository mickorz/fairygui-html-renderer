## 技术决策

- **实时扫描，不建持久索引**：每次搜索遍历全部包组件构建场景树并匹配（本地工程量级毫秒级）；若阶段 D 实测变慢再引入 mtime 缓存（ponytail 边界标注）
- 搜索范围：节点 name / id / 可读路径 instancePath 的不区分大小写子串匹配
- 深度定位走 URL 参数：`/view?component=X&focus=<stableKey>`——可分享、可被 MCP 直接构造，无 postMessage 协议负担
- 已知边界：FairyGUI 画布 stage 为固定尺寸 overflow:hidden，被裁剪节点（如滚动列表内）只能高亮标注，无法滚动到——如实定位到 iframe 文档层
