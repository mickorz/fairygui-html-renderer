### L8 组件内容超出画布的显示（已实现，2026-11-09）

- 发现：2026-11-09 工作台（/?project=fgui_game_42324）查看 BoxKaWuXingMahAniView 时：组件子元素超出画布的部分被裁剪不显示；FairyGUI 编辑器原本**超出画布的内容也显示**（舞台无限延伸，画布只是边界标记，方便查看溢出内容）。
- 实现（当日触发解决）：
  - `renderHtml` 加 `clip` 选项（默认 true 保持现状）：clip=false 时 stage `overflow:visible` + 画布虚线框标记（`border:1px dashed #9a9a9a`）+ body padding 48 + `overflow:auto`（溢出内容可滚动查看，负向溢出在留白区可见）；
  - `/view` 路由加 `clip` 查询参数：**显式 clip=0 才不裁剪**，未传默认裁剪（/api/screenshot 的 bare 截图与既有链路零影响）；
  - 工作台 iframe（canvas-host）加 `&clip=0`：工作台默认不裁剪（编辑器风格方便查看）；
  - 测试：render-check 2 项 + server-check 3 项（clip=0 visible+虚线框 / 未传默认 hidden / bare 仍裁剪）；
  - 视觉实测（BoxKaWuXingMahBackView，真实溢出样本 loader x=-146~1607）：clip=0 溢出内容画布外可见（栏杆穿越虚线框/桌布延伸出框）、裁剪版画布外零泄漏、画布内两版逐元素一致（zai ui_diff_check 三项全过，截图 dev-examples/l8-shots/）。
- 注意：截图对比链路（/api/screenshot bare）保持裁剪（尺寸必须对齐组件 size），编辑器侧画布截图同理按画布边界裁——两侧裁剪行为对称，不裁剪仅供工作台查看。
