> 日期：2026-11-04

### 11. Tree 树形列表（N5b，真实样本 TreeView 包）

| 入口 | 验证点 | 预期 |
|------|--------|------|
| TreeView -> Main | 左侧树列表 | 7 行：Folder 1（下箭头+蓝色开文件夹图标）/ Leaf 1-4（文档图标，无箭头，缩进 15px）/ Folder 2 / Leaf 1（心形 jta 图标） |
| TreeView -> Main | 右侧列表 | 空（tree2 无 item，运行时构建） |

## 批量回归入口（快速全览）

左侧包名旁无全览页时，逐个点以下组件即可覆盖上述全部验证点：

`Demo_Button` -> `Demo_Label` -> `Demo_Text` -> `Demo_ProgressBar` -> `Demo_Slider` -> `Demo_ComboBox` -> `Demo_Component` -> `Demo_MovieClip` -> `Demo_Controller` -> `TreeView(Main)` -> `WindowB` -> `Main` -> `Bag(Bag) -> BagWin`

13 个组件，约 3 分钟过完。

## 已知接受差异（不算 bug）

- 滚动条外观为浏览器默认（FairyGUI 皮肤滚动条属 GScrollBar 运行时，N1 附带项）
- ComboBox 不弹下拉、Slider 不可拖、按钮不可点（运行时交互，见决策文档 N2/N3/N6/N7）
- 位图字体字号固定（FairyGUI BMFont 语义忽略 fontSize）
