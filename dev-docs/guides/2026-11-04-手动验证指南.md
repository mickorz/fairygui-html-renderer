# 手动验证指南（阶段 K 补丁系列 ~ 阶段 Q）

> 日期：2026-11-04（2026-11-09 更新至阶段 Q）
> 适用：渲染验证（按钮 icon / 九宫格 / 字体 / 扩展分支 / N1 可滚容器 / N10 动画 / N5b 树）+ 工作台 + 资产索引/图谱/场景 diff/XML 写出（阶段 O/P/Q）
> 入口：`npm run serve` 后浏览器打开 http://localhost:7788/ ，左侧选包 -> 展开组件点击预览。
> 服务：tsx watch 长驻（端口 7788，工程根 FGUI_PROJECT_ROOT 默认 ./CC-Default）；改代码自动重启，但浏览器页面需手动刷新；页面行为异常时先 `netstat -ano | findstr 7788` 确认进程启动时间晚于代码提交时间。

### 资产索引与图谱接口（阶段 P/Q）

**参数形态（易踩坑）**：凡带 `component`/`a`/`b`/`file` 的接口，组件一律用 `assets/` 下**相对路径**（含 `components/` 层），如 `Basics/components/Button.xml`；不是 `包名:文件` 冒号形式，也不是不含 `components/` 的短路径。错形态返回 404 "组件不存在或路径越界"。

| 验证点 | URL / MCP 工具 | 预期 |
|--------|---------------|------|
| 索引检索 | `/api/ui-assets?q=slider` 或 MCP `search_ui_assets` | 命中 SliderFix/Slider 系组件；stats 含 entryCount/buildMs；真实工程 parseFailures 为空 |
| 反向引用 | `/api/ui-assets/usage?file=Basics/components/Button3.xml` 或 MCP `find_component_usages` | 被 Basics/Demo_Button.xml 引用 |
| 组件图谱 | `/api/component-graph`（全图）或 `?key=Basics/components/Button.xml`（邻域，路径或 pkgId.resId 皆可）或 MCP `get_component_graph` | 节点/边/环/枢纽排行（Button10.xml 入度 21 首位）；邻域含 uses/usedBy/inCycle |
| 场景 diff | `/api/scene-diff?a=X&b=Y` 或 MCP `diff_component_scenes` | added/removed/moved/changed 四分类 + 属性级路径（如 attrs.text）；夹具 DiffA->DiffB：added 1/removed 1/changed 3 |
| XML 写出 | POST `/api/xml-write` {component, html} 或 MCP `write_component_xml` | 返回合并写出的 XML 文本（属性级覆盖生效、gear/controller/扩展元素保留、结构增删移报诊断）；不落盘 |

**场景 diff 手动示例**（浏览器直接打开）：

```
http://localhost:7788/api/scene-diff?a=Basics/components/Button.xml&b=Basics/components/Button1.xml
```

预期 stats：`{matched: 5, added: 0, removed: 0, moved: 0, changed: 5}`（两份按钮皮肤同构，属性全变、结构不变 -> 零假 moved）。

**XML 写出手动示例**（cmd 单行）：

```
curl -X POST http://localhost:7788/api/xml-write -H "Content-Type: application/json" -d "{\"component\":\"Basics/components/Button.xml\",\"html\":\"<div></div>\"}"
```

空 html 合并写出 = 原样返回 XML（nodeCount 5 / appliedChanges 0 / diagnostics 0）。改文本验证覆盖：把 html 换成渲染器产物并改其中一段 text，返回的 XML 对应 `<text ...>新值</text>` 且 appliedChanges 计数 > 0。

**MCP 工具全集（9 个）**：`list_components` | `locate_component` | `render_component` | `screenshot_component` | `search_ui_assets` | `find_component_usages` | `get_component_graph` | `diff_component_scenes` | `write_component_xml`（前四为渲染定位链，后五为资产/图谱/diff/写出链）。

## 多工程切换（阶段 R：P0-A 服务端 + P0-B 前端工作台）

服务为多工程注册目录模式（projects/ 下 CC-Default 官方 Demo + fgui_game_42324 玄物麻将），工作台顶栏有工程切换下拉。所有 API 加可选 `?project=` 参数（缺省 = CC-Default；未知工程 404）。**URL 是工程权威**（`/?project=xxx` 可直达与分享），localStorage 只记忆上次选择。

工作台验证（顶栏下拉）：

| 验证点 | 操作 | 预期 |
|---|---|---|
| 工程切换 | 顶栏下拉选另一工程 | URL 变 ?project=xxx；包树重载（切换瞬间中止旧请求，无旧数据闪烁）；画布清空 |
| 打开组件 | 切换后点组件 | iframe src 与画布内图片/字体 URL 均带 ?project=（F12 网络面板核对） |
| 刷新恢复 | 切工程后 F5 | 工程不变（URL 权威）；组件不恢复（预期，未做组件持久化） |
| 双标签页 | 两个标签各选不同工程 | 各自渲染各自工程互不干扰（工程是请求上下文不是服务状态） |
| URL 直达 | 新标签开 /?project=fgui_game_42324 | 直接进麻将工程（不经 localStorage） |

API 直连验证（不经工作台）：

## 已知接受差异（不算 bug）

- 滚动条外观为浏览器默认（FairyGUI 皮肤滚动条属 GScrollBar 运行时，N1 附带项）
- ComboBox 不弹下拉、Slider 不可拖、按钮不可点（运行时交互，见决策文档 N2/N3/N6/N7）
- 位图字体字号固定（FairyGUI BMFont 语义忽略 fontSize）
- 场景 diff：无 id 同类型兄弟的中间插入会从插入点起报属性变化链（顺序配对边界；有 id 节点不受影响）
- XML 写出：只做属性级覆盖；结构增删移不在范围（报诊断不静默）；服务只读——返回文本不落盘
- XML 写出：解析模型未保留的根属性（bgColor/scrollBar 等）不会出现在输出（解析模型是唯一真源）
