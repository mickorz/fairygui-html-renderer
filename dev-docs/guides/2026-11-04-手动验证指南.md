# 手动验证指南（阶段 K 补丁系列 ~ 阶段 N）

> 日期：2026-11-04
> 适用：最近五轮修改（按钮 icon / 九宫格修复 / 字体两批 / GButton/ComboBox/ProgressBar/Slider/Label/Tree 扩展分支 / N1 可滚容器）
> 入口：启动 `npm run serve` 后浏览器打开 http://localhost:7788/ ，左侧选包 -> 展开组件点击预览。
> 注意：改代码后 server 自动重启（tsx watch），但浏览器页面需手动刷新。

## 工作台（http://localhost:7788/ ，三栏）

| 验证点 | 操作 | 预期 |
|--------|------|------|
| 三栏布局 | 打开首页 | 左（工程组件树 + Scene Tree）/ 中（画布）/ 右（Inspector）+ 顶部工具栏 |
| 打开组件 | 左上展开包 -> 点组件行 | 画布渲染该组件；Scene Tree 列节点（默认展开第一层）；顶栏显示文件名与尺寸 |
| 树选 -> 画布 | 点 Scene Tree 行 | 画布对应节点金色高亮；Inspector 显示该节点属性分组（Basic/Transform/Image/Text/Component/Advanced/Diagnostics，空组隐藏） |
| 画布选 -> 树 | 点画布节点 | Scene Tree 展开父链并定位闪烁该行；Inspector 同步 |
| Inspector 分组 | 选中后逐组展开 | Basic 含 key/path（复制按钮）；Advanced 含 attrs JSON + gears；未支持节点有 Diagnostics 组 |
| 搜索 | 左上输入组件名/资源 id/包名回车 | 树区切平铺命中列表；清空恢复包树 |
| 定位 | 打开组件后点"定位" | 展开所在包并滚动闪烁当前组件行 |
| 缩放 | 顶栏 -/100%/+/Fit | 画布 transform 缩放；Fit 适配可视区（组件尺寸大时如 10%）；拖分隔条可调栏宽（localStorage 记忆） |
| 徽章 | Demo_Button | component 行带"展开"（来源文件）；未支持节点带"未支持" |
| 组件关系条 | 打开 Basics/components/Button.xml | 画布上方"组件关系"条：引用了=无；被引用=Demo_Button.xml 芯片（src·路径）；点芯片跳转该组件 |

## 批量回归入口（快速全览）

左侧包名旁无全览页时，逐个点以下组件即可覆盖上述全部验证点：

`Demo_Button` -> `Demo_Label` -> `Demo_Text` -> `Demo_ProgressBar` -> `Demo_Slider` -> `Demo_ComboBox` -> `Demo_Component` -> `Demo_MovieClip` -> `Demo_Controller` -> `TreeView(Main)` -> `WindowB` -> `Main` -> `Bag(Bag) -> BagWin`

13 个组件，约 3 分钟过完。

## 已知接受差异（不算 bug）

- 滚动条外观为浏览器默认（FairyGUI 皮肤滚动条属 GScrollBar 运行时，N1 附带项）
- ComboBox 不弹下拉、Slider 不可拖、按钮不可点（运行时交互，见决策文档 N2/N3/N6/N7）
- 位图字体字号固定（FairyGUI BMFont 语义忽略 fontSize）
