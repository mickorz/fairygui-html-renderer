## 批量回归入口（快速全览）

左侧包名旁无全览页时，逐个点以下组件即可覆盖上述全部验证点：

`Demo_Button` -> `Demo_Label` -> `Demo_Text` -> `Demo_ProgressBar` -> `Demo_Slider` -> `Demo_ComboBox` -> `Demo_Component` -> `Demo_MovieClip` -> `Demo_Controller` -> `WindowB` -> `Main` -> `Bag(Bag) -> BagWin`

12 个组件，约 3 分钟过完。

## 已知接受差异（不算 bug）

- 滚动条外观为浏览器默认（FairyGUI 皮肤滚动条属 GScrollBar 运行时，N1 附带项）
- ComboBox 不弹下拉、Slider 不可拖、按钮不可点（运行时交互，见决策文档 N2/N3/N6/N7）
- 位图字体字号固定（FairyGUI BMFont 语义忽略 fontSize）
- jta 只显示单帧（播放属 N10）
