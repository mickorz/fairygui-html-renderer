## 经验索引

- npm 11 allow-scripts 拦截 esbuild postinstall，需 `npm approve-scripts esbuild`，tsx 才可用
- TypeScript 7（tsgo）下泛型 `T | T[] | undefined` 参数推断异常，调用处显式 `asArray<Record<string,string>>(...)` 规避
- 原版格式 package.xml 的 image 条目带 width/height/scale9grid，组件 XML 无 fileName（与 OpenFairy fork 格式相反），资源解析必须走 package.xml 索引
