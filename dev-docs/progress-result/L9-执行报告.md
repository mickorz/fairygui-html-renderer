# L9 执行报告：左栏对齐原版 FairyGUI 编辑器

## 背景

用户对照原版 FairyGUI 编辑器（截图 dev-examples/screenshots/BoxKaWuXingMahAniView.win.png）发现 web 工作台左侧栏形态与原版完全不一样，要求改成一致的形态。

## 原版目标形态（分析截图所得）

- 左栏上下两大段，高度比约 2:1（资源库 65% / 显示列表 35%）
- 上段资源库：标签页（资源库）+ 搜索/工具行 + 包列表（包图标+包名+资源数），包展开显示包内全部资源（组件/图片/字体/影片剪辑按文件夹分层）
- 下段显示列表：标签页（显示列表）+ 搜索行 + 节点树（图标+名字，选中行蓝色整行高亮，无名节点显示 id）

## 改动清单

| 文件 | 改动 |
|------|------|
| src/scene/workspace.ts | 新增 ResourceListing + listResources：包内全量资源清单（pkg.resources 映射 kind: component/image/font/movieclip/other，组件带 component 相对路径） |
| src/server/server.ts | /api/packages/{name}/components 扩展返回 resources 字段（components 保留向后兼容） |
| src/editor/project-tree.ts | 重写为资源库树：包 -> 资源文件夹（package.xml path 分层递归，支持嵌套 fnt/piao/）-> 资源行（类型图标 C/I/F/J/· + 名字 + id 徽章 + 内部标记）；组件行点击打开，图片/字体/动画行只展示（title 给类型与路径）；搜索过滤扩展到资源名/资源 id/类型 |
| src/editor/scene-tree.ts | 显示列表节点行只显示名字（去类型文字前缀，类型走图标与 title；无名节点显示 id，与原版一致） |
| src/editor/editor-page.ts | pane-head 改 pane-tabs 标签页形态（资源库/显示列表）；#proj-pane 高度 45% -> 65%（对齐原版 2:1）；选中行背景 #3a5068 -> #3d6ab0（对齐原版蓝）；包图标/文件夹图标配色；搜索框 placeholder 适配资源树 |
| tests/server-check.ts | 补 L9 断言：resources 字段返回组件（带 component 路径）+ 图片资源 + 全量多于组件清单 |

## 与原版的已知差异（设计取舍）

- 图标为字母占位（P/D/C/I/F/T），原版为图形化小图标（信息量等价，后续可换 SVG）
- 资源 id 以徽章形式直接显示在树行内（原版默认不显示，属增强项）
- 深色主题保持工作台既有风格（原版为浅色，未在本次要求范围内）
- 原版底部预览按钮窄条属编辑器主界面元素，工作台无对应功能，未做

## L9b 深化：像素级视觉复刻（用户追加"需要"）

首轮完成后用户要求像素级复刻剩余差异。zai 详查原版截图发现重要事实：原版编辑器截图本身即深色主题，主题天然对齐，剩余差异集中在图标形态与色彩。

### 迭代过程（zai 对比四轮：78% → 83% → 89% → 92%）

| 轮次 | 修复项 | 相似度 |
|------|--------|--------|
| 第 2 轮 | 字母占位图标 -> SVG 图形化（包/文件夹/资源/节点全套）；去 id 徽章与包数量徽章；标签页改文字亮度式；行高 22px；雅黑 12px | 78% |
| 第 3 轮 | 选中蓝降饱和；包图标渐变；底色暖灰 #2d2d2d；面板底色 | 83% |
| 第 4 轮 | 底色 #3f3f3f；头部条亮于列表区（#464646/#3f3f3f 明度分层）；选中蓝统一 #4d6a85；包图标改等轴测三面立方体（顶 #6aa6d8/左 #3d7ab5/右 #2a5a8c/纯白描边）；component 节点图标改立方体线框；行高锁 26px；展开箭头蓝 #6fa1d8；滚动条深灰细条；折叠箭头 opacity 0.55；tab 加图标（房子/三横线）；文字层级色（包名 #c9c9c9/资源 #b9b9b9） | 92% |

### 不做的项（静态工作台无对应功能，不做假 UI）

- 收藏夹/搜索/动效 tab（无对应功能）
- "所有包"下拉 + 刷新/设置等工具图标行（搜索框已覆盖过滤）
- 显示列表眼睛/锁列、行尾圆点（显隐/锁定是编辑器交互功能）
- 底部预览按钮（无运行时预览功能）

### 踩坑记录

- 编辑 CSS 时误删 `.tree .row .caret` 三行规则（oldText 范围过大连带匹配），下一轮发现 caret 失样式后补回——多行块替换前先核对 oldText 覆盖的每一行去向
- browser_screenshot 与 chrome_devtools_take_screenshot 是两套独立浏览器，截错窗口得到全白截图（zai 误报"应用白屏"）；两套工具不可混用截图对象
- AniView 组件全为 loader3D（unsupported 不入树），显示列表空属正常边界，验证选中样式需换 playerHead
