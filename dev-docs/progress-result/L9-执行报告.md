# L9 执行报告：左栏对齐原版 FairyGUI 编辑器

## 背景

用户对照原版 FairyGUI 编辑器（截图 dev-examples/screenshots/BoxKaWuXingMahAniView.win.png）发现 web 工作台左侧栏形态与原版完全不一样，要求改成一致的形态。

## 原版目标形态（分析截图所得）

- 左栏上下两大段，高度比约 2:1（资源库 65% / 显示列表 35%）
- 上段资源库：标签页（资源库）+ 搜索/工具行 + 包列表（包图标+包名+资源数），包展开显示包内全部资源（组件/图片/字体/影片剪辑按文件夹分层）
- 下段显示列表：标签页（显示列表）+ 搜索行 + 节点树（图标+名字，选中行蓝色整行高亮，无名节点显示 id）

## 改动清单

| 文件 | 改动 |
|------|------|
| src/scene/workspace.ts | 新增 ResourceListing + listResources：包内全量资源清单（pkg.resources 映射 kind: component/image/font/movieclip/other，组件带 component 相对路径） |
| src/server/server.ts | /api/packages/{name}/components 扩展返回 resources 字段（components 保留向后兼容） |
| src/editor/project-tree.ts | 重写为资源库树：包 -> 资源文件夹（package.xml path 分层递归，支持嵌套 fnt/piao/）-> 资源行（类型图标 C/I/F/J/· + 名字 + id 徽章 + 内部标记）；组件行点击打开，图片/字体/动画行只展示（title 给类型与路径）；搜索过滤扩展到资源名/资源 id/类型 |
| src/editor/scene-tree.ts | 显示列表节点行只显示名字（去类型文字前缀，类型走图标与 title；无名节点显示 id，与原版一致） |

| tests/server-check.ts | 补 L9 断言：resources 字段返回组件（带 component 路径）+ 图片资源 + 全量多于组件清单 |

## 与原版的已知差异（设计取舍）

- 图标为字母占位（P/D/C/I/F/T），原版为图形化小图标（信息量等价，后续可换 SVG）
- 资源 id 以徽章形式直接显示在树行内（原版默认不显示，属增强项）
- 深色主题保持工作台既有风格（原版为浅色，未在本次要求范围内）
- 原版底部预览按钮窄条属编辑器主界面元素，工作台无对应功能，未做
