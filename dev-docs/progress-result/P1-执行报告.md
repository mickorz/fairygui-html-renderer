## gear 编码结论（读 submodule 源码验证）

- `gearSize` values=`-|64,80|-|-`：`|` 是页分隔符，每页 `w,h` 逗号分量，`-` = 该页无变化用 default，4 组对 4 页
- `gearXY` 同理（如 `0,10|2,13|0,10|2,13`）
- `gearColor` values 编码与页数不匹配（BagButton 3 组 vs 4 页），默认页值均为无变化——**P1 收窄不实现**，列未支持清单
- 依据：thirdparties submodule Runtime/Gear.cs、GearColor.cs（只读参考编码行为）
